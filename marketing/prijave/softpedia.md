**Short description (≤ 160):** Design custom kitchens and cabinets in 3D and get a millimetre-exact cut list, hardware list and price. Built by a cabinet maker.
**Long description:**
TOPICA is a Windows application for joinery workshops that build custom panel furniture. Draw the room (walls, ceiling height, services), place cabinets from a catalog built to the European standard (System 32, edge banding, 35 mm cup hinges, drawer systems, plinth, worktop, end panels) and the program derives every panel automatically. Outputs: 3D view with real decors, cut list per cabinet and per material, a copy-ready “By size” view, edge banding length, hardware list, board usage and price from your own prices, PDF printing. Works offline, no account; a project is a single file. Languages: Serbian, English. Not included in this version: CNC export, sheet nesting.
